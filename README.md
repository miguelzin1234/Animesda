# 🍥 Anime Tracker

PWA hospedado pelo GitHub Pages.

Como usar:
1. Envie todos os arquivos para um repositório GitHub.
2. Ative GitHub Pages.
3. Abra o link pelo celular.
4. O navegador mostrará a opção de instalar o aplicativo.

Arquivos principais:
- index.html
- manifest.json
- service-worker.js
- icone.jpg
